# Mutual Fund Industry Analysis (2026)

## Project Overview
This project provides an in-depth analysis of the Indian Mutual Fund industry, focusing on AUM growth, SIP trends, investor demographics, and sector allocation. The goal is to derive actionable insights from transaction data and visualize market shifts between 2024 and 2026.

## Key Features
- Trend Analysis: Tracking NAV history and AUM growth over time.
- Investor Insights: Demographics analysis (Age, Gender, City Tier).
- Portfolio Analytics: Sector-wise allocation and NAV correlation heatmap.
- Geographic Reach: Analysis of T30 vs. B30 city performance.

## Tech Stack
- Domain: Fintech | Financial Analytics
- Language: Python
- Libraries: Pandas (Data Processing), Plotly (Visualization)
- Database: SQLite (SQL queries for data retrieval)
- Version Control: Git & GitHub

## Key Findings
1. Sustainable SIP Growth: Monthly inflows indicate strong retail discipline.
2. Folio Expansion: Significant increase from 13.26 Cr to 26.12 Cr.
3. Youth Participation: Median investor age is 28 years.
4. B30 Penetration: Increasing footprint in Tier-2 and Tier-3 cities.
5. Digital-First: 80% of transactions are executed through digital channels.
6. Financial Stability: Financial services remain the top sector in portfolios.
7. High Correlation: Equity funds show high correlation to broader market indices.
8. Gender Parity: Steady improvement in female investor participation.
9. AUM Milestone: Industry crossed the 81 Lakh Crore mark.
10. Growth Potential: Low AUM-to-GDP ratio suggests long-term growth opportunities.
